# Changelog

All notable changes to **Power Bar Colour Picker** will be documented here.

## v1.0.2

### Compatibility
- Updated the interface version for WoW Classic TBC Anniversary 2.5.6.
- Fixes the addon being shown as **"Out of date"** in the AddOns menu.

---

## v1.0.1

### Changed
- Improved the layout of the colour picker window.
- Increased the overall window width.
- Improved spacing between the colour options and reset buttons.
- Adjusted power type button sizes to better fit their labels.
- Made reset buttons consistent in size with the other controls.
- Removed the redundant "Editing Mana/Rage/etc." text.
- The currently selected power type is now indicated by the highlighted button.

### Other
- General UI improvements and cleanup.

---

## v1.0.0

### Initial Release
- Initial release of **Power Bar Colour Picker** for WoW Classic TBC Anniversary.
- Added `/pbcp` command to open the colour picker.
- Added custom power bar colours for:
  - Mana
  - Rage
  - Energy
  - Focus
  - Runic Power
- Added individual reset buttons for each power type.
- Added persistent colour settings using SavedVariables.
- Added addon-loaded message to the chat window.
